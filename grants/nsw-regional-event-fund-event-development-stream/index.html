NSW Regional Event Fund · Event Development stream

NSW 区域活动基金 · Event Development

NSW Regional Event Fund · Event Development stream is a grant / funding program from Destination NSW. Area: Regional NSW (not Greater Sydney). Amount: One-off grant up to A$50K, no equity. Deadline: 31 December 2026. Who can apply: Only for events that have completed Flagship triennial funding; must contact Destination NSW before applying.
